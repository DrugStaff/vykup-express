# Výkup Express — сайт

Готовий сайт викупу: головна, 5 сторінок категорій (золото, авто, техніка, годинники й люкс, інше), сторінка GDPR і адмінка із заявками. Три мови: чеська, німецька, російська (перемикач у шапці, мова запам'ятовується).

```
index.html          головна
zlato.html          золото й срібло
auta.html           авто й мотоцикли
elektronika.html    техніка
luxus.html          годинники й люкс
ostatni.html        все інше
nemovitosti.html    квартири, будинки, ділянки + анкета в 3 кроки
gdpr.html           ochrana osobních údajů
admin.html          адмінка (заявки, статуси, ціни, нотатки)
assets/config.js    ← ТУТ контакти й ключі Supabase
assets/i18n.js      всі тексти трьома мовами
assets/style.css    дизайн
assets/main.js      анімації, мови, форма
assets/store.js     збереження заявок (демо або Supabase)
assets/img/         картинки сайту (3D-візуалізації)
supabase/           SQL для бази + функція для Telegram
```

## 0. Показати Міхалу (нічого не треба налаштовувати)

Поки в `config.js` порожні ключі Supabase, сайт працює в **демо-режимі**: заявка з форми зберігається в браузері, і її одразу видно в `admin.html` на тому ж пристрої. В адмінці вже лежать 4 приклади заявок з позначкою «Ukázka».

Сценарій показу: відкрити сайт → перемкнути CZ / DE / RU → зайти на сторінку золота → заповнити форму з фото → відкрити адмінку (посилання «Pro tým» внизу) → там нова заявка, міняємо статус і ціну.

## 1. Контакти

Відкрий `assets/config.js` і впиши телефон, WhatsApp (тільки цифри з кодом країни), Telegram і e-mail Міхала, плюс назву фірми та IČO для сторінки GDPR. Більше ніде контакти міняти не треба.

## 2. Хостинг на GitHub Pages (безкоштовно)

1. github.com → **New repository** → назва, напр. `vykup-expres` → Public → Create.
2. **Add file → Upload files** → перетягни ВСІ файли й папки з цієї папки (разом з `assets` і `supabase`) → Commit.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
4. За хвилину-дві сайт буде на `https://ТВІЙ-НІК.github.io/vykup-expres/`.

## 3. База заявок і адмінка (Supabase, безкоштовний тариф)

1. supabase.com → **New project**. Регіон: **Central EU (Frankfurt)**. Пароль бази збережи.
2. **SQL Editor → New query** → встав увесь `supabase/schema.sql` → **Run**. Створиться таблиця заявок, сховище для фото й права доступу.
3. **Authentication → Sign In / Providers**: вимкни *Allow new users to sign up* (щоб ніхто чужий не зареєструвався).
4. **Authentication → Users → Add user → Create new user**: e-mail і пароль Міхала (і свій). Це логіни в адмінку.
5. **Project Settings → API**: скопіюй *Project URL* і ключ *anon public* у `config.js` (`supabaseUrl`, `supabaseAnonKey`). Anon-ключ публічний, це нормально: права обмежені SQL-політиками, відвідувач може тільки надіслати заявку.
6. Залий оновлений `config.js` на GitHub. Тепер форма пише в базу, а `admin.html` просить логін.

Нюанс безкоштовного тарифу: якщо проєкт тиждень ніхто не відкриває, Supabase ставить його на паузу. Поки приходять заявки й Міхал заходить в адмінку, цього не буде. Якщо заснув, у дашборді є кнопка *Restore*.

## 4. Сповіщення у WhatsApp (і за бажанням у Telegram)

Функція `telegram-notify` (назва історична, вона шле й у WhatsApp), вебхук на нові заявки, `ADMIN_URL` і `WHATSAPP_PHONE` уже налаштовані.

**WhatsApp через CallMeBot (безкоштовно, тільки текст):**
1. Міхал зберігає в контакти номер **+34 644 44 21 48** (CallMeBot).
2. Пише йому у WhatsApp рівно: `I allow callmebot to send me messages`
3. Протягом пари хвилин приходить відповідь «API Activated…» з **apikey**. Якщо не прийшло, спробувати знову через 24 години.
4. Supabase → **Edge Functions → Secrets**: `CALLMEBOT_APIKEY` = цей ключ → **Save**.
Фото у WhatsApp не приходять, у повідомленні буде кількість фото, а самі фото — в адмінці.

**Telegram (необов'язково, з фото):** @BotFather → `/newbot` → токен; Start у боті; Id з @userinfobot; секрети `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`.

Захист: функція бере заявку з бази за її id, тож підробленим запитом нічого не надіслати.
Примітка: CallMeBot — сторонній безкоштовний сервіс без гарантій. Для «серйозного» режиму є офіційний WhatsApp Business API від Meta (платний, з перевіркою бізнесу).

## 6. Перед запуском реклами перевірити з Міхалом

- Обіцянки на сайті: «nabídka do 15 minut», виїзд по Чехії й прикордонню Німеччини, оплата готівкою або переказом, оформлення переоформлення авто. Якщо щось не так, тексти міняються в `assets/i18n.js` (або скажи мені, перепишу).
- Сторінка GDPR: назва фірми, IČO, адреса, строк зберігання заявок (зараз написано 6 місяців). Краще дати глянути юристу чи бухгалтеру.

- Логотип і назва «Výkup Express» робочі. Якщо Міхал вибере іншу назву, вона міняється в `i18n.js` і в шапці HTML-файлів.

## 7. Картинки

У `assets/img` лежать 3D-візуалізації в стилі студійної предметки, я їх відрендерив спеціально під сайт, тож авторських прав чужих там нема. Для кожної категорії є три файли:
- `<категорія>-hero.jpg` 1200×1500 — велике фото вгорі сторінки;
- `<категорія>-wide.jpg` 2000×1000 — широка смуга посередині сторінки;
- `<категорія>-thumb.jpg` 640×480 — мініатюра в списку на головній.
Плюс `hero-wide.jpg` 2400×1030 для смуги на головній.

Якщо Міхал дасть справжні фото (свої зливки, авто, команду, офіс), просто заміни файл файлом з тією самою назвою й приблизно тими самими пропорціями. Справжні фото продають довіру краще за будь-яку графіку.

## 8. Нерухомість: що звірити з Міхалом

На сторінці нерухомості є обіцянки, які мають бути правдою: пропозиція за 48 годин, дзвінок за 24 години, юрист і збори за наш рахунок, оплата через адвокатську або банківську úschovu, викуп з іпотекою чи екзекуцією, дата виїзду на вибір продавця, іноді зворотна оренда. Якщо щось не так, скажи — перепишу.

Анкета зберігає всі відповіді в колонці `details` (тип, адреса, диспозиція, площа, власність, стан, обтяження, хто живе, коли продати, ціна, e-mail). В адмінці вони показуються окремим блоком, у Telegram приходять одним повідомленням. Якщо таблиця в Supabase вже була створена раніше, просто ще раз запусти `supabase/schema.sql` — він додасть колонку й нову категорію.
